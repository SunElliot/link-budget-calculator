A free toolkit for satellite link design

SatTools is a collection of browser-based calculators for designing and analysing satellite communication links — aimed at LEO smallsat / CubeSat engineers, ground-station operators, radio amateurs and students. Every tool runs entirely on your device; nothing is uploaded, and there is no signup.

Start with the link budget calculator to size a link end to end, use the Doppler and pass predictor tools to plan ground-station tracking, the antenna and G/T calculators to spec your hardware, and the rain-fade tool to set your margin at Ku/Ka-band. The frequency band reference ties it together.
