🧪 SatTools Regression Tests

Zero dependencies. Exercises the shipped code — the calculator pages are loaded in hidden same-origin iframes and their real functions are called directly.

Must be served over http(s) — file:// blocks same-origin iframe access. Locally: python3 -m http.server, then open http://localhost:8000/tests.html. Not linked from the tool nav and excluded from sitemap.xml on purpose; it is a development page, not a calculator.

Service worker: sw.js serves non-document requests cache-first, so a worker left over from a previous visit can hand these tests a stale modcod.js or a stale page and let them pass against code that is no longer on disk. The suite therefore unregisters every worker and drops the sattools-* caches before it reads anything, reloading once to escape an existing controller. That reload is expected.
